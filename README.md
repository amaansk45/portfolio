A modern, fast, and responsive portfolio web application engineered for **Amaan Shaikh**, showcasing Full Stack & Django development expertise, featured projects, technical competencies, academic credentials, and interactive resume viewer.

---

## ✨ Features

- 🌓 **Dynamic Theme Engine**: Seamless toggle between Dark and Light themes with persistent preference storage.
- ⚡ **Lightning Performance**: Built with Vite 6 & React 18 for instantaneous loading and optimal Lighthouse scores.
- 📱 **Fully Responsive**: Mobile-first design architecture crafted with Tailwind CSS.
- 📄 **Interactive Resume Modal**: In-browser PDF preview and instant download capability.
- 🎨 **Modern Glassmorphic UI**: Sleek gradients, animated borders, and modern micro-interactions.
- 📬 **Interactive Contact Hub**: Direct contact triggers for email, WhatsApp, and LinkedIn networking.
- 🚀 **Automated CI/CD**: Automatic deployment pipeline with GitHub Actions.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Tailwind CSS, React Icons
- **Build Tool**: Vite 6
- **Deployment**: GitHub Pages / Vercel
- **Styling**: Vanilla CSS Variables & Tailwind Utility Framework

## 💻 Local Development Setup

To run this portfolio locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/amaansk45/portfolio.git

# 2. Navigate to project root
cd portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:5173` to explore the application locally.

---

## 📦 Production Build

```bash
npm run build
npm run preview
```
